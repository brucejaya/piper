# Pricing

Piper's protocol, transport, pairing model, CLI, and reference implementations remain open source. Payment applies only to the official iOS app experience.

## Products

- Lifetime: `app.piper.ios.lifetime`
- Annual: `app.piper.ios.annual`
- Monthly: `app.piper.ios.monthly`

Lifetime should be presented first in the app because Piper does not depend on ongoing hosted infrastructure for the core control plane.

## Entitlement Boundary

An active entitlement unlocks official app features, App Store distribution value, purchase restoration, and polished mobile workflows.

It does not grant protocol access, pair an agent, modify an agent allowlist, or restrict third-party clients. Pairing remains a public-key trust decision between a Piper agent instance and a client peer.
